# Свадебный сайт — Юля & Даниил

Фронтенд свадебного сайта-приглашения, сделанный на React + Vite.

## Стек

- **React** — UI
- **Vite** — сборка
- **CSS** — стили (без фреймворков)

## Запуск

```bash
npm install
npm run dev
```

## Деплой на GitHub Pages

```bash
npm run deploy
```

Сайт доступен по адресу: https://Ushikava.github.io/wedding/
